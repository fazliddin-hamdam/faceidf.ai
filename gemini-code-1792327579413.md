# Face ID AI: Semantic Face Search System

## Proje Özeti
Kullanıcıdan alınan Türkçe fiziksel özellik metinlerini kullanarak, veri tabanındaki (LFW) yüz görselleri arasında anlamsal arama (semantic search) yapan ve en yakın eşleşmeyi Telegram Mini App üzerinden gösteren yapay zeka sistemi. 

Bu döküman, Claude AI (veya benzeri bir LLM) asistanına verilerek projenin kodlanmasını otomatize etmek için bir yol haritası (Prompt/Plan) olarak hazırlanmıştır.

## Mimari ve Teknolojiler
* **AI Modeli (Vektörleştirme):** `clip-ViT-B-32` (SentenceTransformers)
* **LLM (Metin Çevirisi):** Claude Pro (Anthropic API) - Türkçe metni İngilizce CLIP arama sorgusuna çevirmek için.
* **Veritabanı:** Qdrant (Yerel dosya tabanlı, Cosine Similarity)
* **Backend:** Python + FastAPI 
* **Frontend (Kullanıcı Arayüzü):** HTML/JS/CSS (Telegram WebApp API entegreli)
* **Hosting:** Frontend için GitHub Pages
* **Açık Veri Seti:** Labeled Faces in the Wild (LFW) - ~13.000 görsel

## Claude İçin Geliştirme Görevleri (Adım Adım)

### Görev 1: Veri Hazırlığı ve Qdrant Vektör Veritabanı
**Açıklama:** LFW veri setindeki görselleri CLIP modeli ile 512 boyutlu vektörlere dönüştürüp yerel Qdrant veritabanına kaydeden Python betiği.
* **Beklenen Çıktı:** `process_faces.py`
* **Gereksinimler:** `sentence-transformers`, `qdrant-client`, `Pillow`. Her görsel için UUID oluşturulmalı, görsel dosya yolu `payload` içine eklenmeli.

### Görev 2: FastAPI Backend ve Anthropic (Claude) API Entegrasyonu
**Açıklama:** Arama işlemlerini yönetecek REST API. 
* **Beklenen Çıktı:** `main.py`
* **Gereksinimler:** 
  1. `/search` adında bir POST endpoint'i.
  2. Kullanıcıdan gelen Türkçe metni Anthropic API kullanarak İngilizceye çeviren bir LLM fonksiyonu (Örn: "esmer, sakallı" -> "a photo of a dark skinned, bearded man").
  3. Çevrilen İngilizce metni CLIP ile vektöre çevirme.
  4. Qdrant üzerinde vektör araması (search) yapıp en yakın görsel dosya yolunu ve benzerlik skorunu JSON olarak dönme.
  5. GitHub Pages'tan gelecek istekler için CORS ayarlarının yapılması.

### Görev 3: Telegram Mini App Frontend (GitHub Pages İçin)
**Açıklama:** Telegram içinde açılacak ve FastAPI backend'i ile konuşacak web arayüzü.
* **Beklenen Çıktı:** `index.html`, `style.css`, `app.js`
* **Gereksinimler:**
  1. `telegram-web-app.js` SDK'sının projeye dahil edilmesi.
  2. Responsive, mobil uyumlu, temiz bir input alanı ve "Ara" butonu.
  3. Kullanıcı metni girdiğinde FastAPI backend'ine fetch isteği atacak JS fonksiyonu.
  4. Dönen sonuca göre görselin ve eşleşme yüzdesinin ekranda gösterilmesi.

### Görev 4: Dağıtım ve Bot Bağlantısı
**Açıklama:** Projenin canlıya alınma adımları.
* **Beklenen Çıktı:** Kurulum talimatları (README)
* **Gereksinimler:** Frontend dosyalarının GitHub Pages'a nasıl yükleneceği ve BotFather üzerinden Web App URL'sinin bota nasıl bağlanacağının adım adım yönergesi.
